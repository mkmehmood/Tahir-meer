About the Language System

All content is stored once in English here. The lang.js library contains full English and Urdu dictionaries covering every UI string.

When a visitor clicks the language toggle, the entire DOM is replaced with the Urdu version from the dictionary — no API calls, no delays, works fully offline.

Content you enter here (titles, descriptions, etc.) appears as-is in English mode. The static UI labels (nav, buttons, form fields, etc.) switch automatically via the dictionary.
